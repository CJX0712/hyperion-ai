# ADR-010 确定性合成语料 + 固定种子：可复现优先于规模

状态：已采纳 · 作者：晨星

## 背景
训练数据决定可复现性。真实语料（网页/维基）引入许可、网络、体积三类不可控因素；
huggingface.co 在目标环境不可达，预训练权重不可得。

## 决策
语料由 `corpus.py` 从模板确定性生成（seed=20260923）：
101 篇知识库文档（服务总览/故障排查/配置/运维手册/FAQ）+ 404 条 QA（含 gold doc 与 hard negatives）
+ 8 变体 LM 文本。全部随机路径（BPE、批次采样、负例采样）种子固定。

## 后果
- +：任何机器重训逐位一致；e2e 与评估不依赖网络与外部数据；
- +：评估的 gold/hard-negative 标注是程序生成的，天然无标注噪声；
- −：模型只会回答知识库领域内的问题（这恰是 RAG 系统的边界语义，检索不命中时显式说不知道）；
- 换真实语料时只需替换 corpus.py 的文档源，管线与格式不变。
