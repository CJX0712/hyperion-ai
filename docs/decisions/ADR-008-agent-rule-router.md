# ADR-008 Agent：确定性规则路由器，不让 1.3M 模型发 JSON

状态：已采纳 · 作者：晨星

## 背景
业界主流 ReAct/Function-Calling 让 LM 自己输出结构化工具调用。
1.3M 参数的自训练 LM 在 CPU 预算下无法可靠生成合法 JSON（解析失败率高、幻觉工具名）。

## 决策
- 工具路由用确定性规则（关键词 -> 工具），LLM 只负责最终基于工具观测生成回答；
- 循环有界：maxSteps 钳制 [1,8]，事件流（plan/step/observation/critique/final）全程可追溯；
- 工具失败不中断循环，最终兜底话术明确承认失败。

## 后果
- +：行为完全可测试（S22-S24），无幻觉工具名；
- +：同一套 Agent 框架未来换大模型时只需替换 Planner；
- −：路由泛化能力弱于 LM 规划（诚实权衡：小模型下规则更可靠）。
